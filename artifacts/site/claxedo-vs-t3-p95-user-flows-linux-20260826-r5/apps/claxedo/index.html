Flow 03

Workspace panel

Every interaction answers two user-facing questions: how quickly did the requested surface respond or become usable, and did rendering remain inside the 16.67 ms frame budget? Light, moderate, and heavy vary retained directory and file-tab state while keeping the same complete 24-file Review model.

Animation is presentation, not speed.

Open and close keep each product's production behavior. Their intentional animation duration is not used to name a latency winner; only trusted-input response and p95 frame health are scored. Other actions compare interactive completion and the same 60 Hz evidence. Setup does not scroll Review.

Data-warm, surface-cold file opening.

Each load profile owns a distinct canonical target whose bytes are warm but whose tab and preview have never mounted. The measured input owns first surface creation and paint.

Definitions

What the windows mean

Active memory is measured while completed historical sessions progress across 1 MiB through 128.0 MiB. Idle means the fixed 1 MiB control transcript is fully ready with no benchmark input for the scenario's configured idle window. No live session stream is running.

OpenCode-format completed sessions · GUI performance only · No Web Vitals · No live or terminal agent workload
